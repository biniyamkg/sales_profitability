===========================
POS Profitability Report
===========================

This module provides a detailed POS Profitability Reporting solution for Odoo 17 Community edition.
It enables business owners to analyze profit margins on POS sales using both PDF and Excel reports, with built-in KPIs for data-driven decision making.

Key Features
============

- Profitability Report per POS Configuration
- Filters by Date Range and POS Config
- Product-wise breakdown: Quantity, Cost, Unit Price, Subtotal, Margin, Margin %
- KPI Metrics: Total Sales, Total Cost, Total Margin, Margin Percentage
- Export reports in both PDF and Excel formats
- Excel report includes clean formatting, formulas, and merged KPI headers
- PDF report ready for printing and review
- Compatible with multi-company setup

Installation
============

To install this module:

1. Download the module and add it to your Odoo `addons` folder.
2. Restart your Odoo server.
3. Enable developer mode.
4. Go to the **Apps** menu and click on **Update Apps List**.
5. Search for "POS Profitability Report" and click **Install**.

Upgrade
============

To upgrade this module:

1. Replace the old module code with the new version in your `addons` folder.
2. Restart your Odoo server.
3. Go to **Apps** > Search for "POS Profitability Report" > Click **Upgrade**.

Configuration
=============

No additional configuration is required after installation.
To generate a report:

1. Navigate to **Point of Sale > Reporting > Profitability Report**.
2. Select the POS Config(s) and date range.
3. Click **Print PDF** or **Export Excel**.

Frequently Asked Questions
==========================

**1. Does this work on Odoo Community edition?**
Yes. This module is fully compatible with Odoo 17 Community edition.

**2. Can we export data to Excel or PDF?**
Yes. You can export the profitability report to both PDF and Excel formats.

**3. Does the report support multiple POS locations?**
Yes. You can generate reports for one or multiple POS configurations at once.

**4. Are KPIs included in the reports?**
Yes. Both PDF and Excel include total sales, cost, margin, and margin percentage.
